# Specification: AI Agent Culture and Engineering Standards Validator (AI Culture Guardian)

This project implements an automated validation engine for software engineering culture and architectural standards for code generated by AI Agents, built with the purely functional and massively parallel **Bend** language running on the **HVM** runtime. The system acts as the automated right hand of technical leadership and culture guardians, auditing and reporting any deviation or violation of established standards.

---

## 1. Objective

Provide a deterministic, high-parallelism, and Spec-Driven Development (SDD) oriented platform that analyzes code and artifacts generated by AI Agents, validating strict adherence to architectural conventions, testing practices, requirements traceability, security, and code contracts, emitting structured compliance audit reports.

---

## 2. Functional Requirements

| ID | Description | Actor | Priority |
| :--- | :--- | :--- | :--- |
| **RF01** | Load and evaluate formal engineering culture rules and code conventions. | Bend Engine / CI | High |
| **RF02** | Evaluate artifacts generated by AI agents using parallel divide-and-conquer binary trees. | Bend Engine | High |
| **RF03** | Detect common AI anti-patterns (lazy code `TODO/pass`, missing tests, hardcoded secrets, loose contracts). | Bend Engine | High |
| **RF04** | Validate traceability between generated code and technical specifications (`spec.md`, RF/RN IDs). | Bend Engine / CLI | High |
| **RF05** | Generate detailed culture compliance reports with severity levels (`BLOCKING`, `WARNING`, `INFO`) and Culture Score (0-100). | Bend Reporter / CLI | High |
| **RF06** | Integrate with CI/CD pipelines and provide CLI with structured outputs (JSON, Markdown, exit code gating). | CLI / GitHub Actions | High |

---

## 3. Non-Functional Requirements

| ID | Category | Description |
| :--- | :--- | :--- |
| **RNF01** | Performance | Parallel evaluation of dozens of files and rules in under 1 second via Bend/HVM. |
| **RNF02** | Determinism | Purely functional, side-effect-free execution within the Bend reduction core. |
| **RNF03** | Portability | Runs seamlessly on CPU (Rust/C HVM) and GPU (CUDA HVM) without logic alterations. |
| **RNF04** | Extensibility | Simple addition of new culture rules via algebraic data types and pattern matching. |

---

## 4. Business Rules

| ID | Rule |
| :--- | :--- |
| **RN01** | **Zero Tolerance for Incomplete Code**: Any code snippet containing `TODO`, `FIXME`, empty stubs, or `pass` in functional blocks generated by AI is classified as a Blocking Violation (P0 Error). |
| **RN02** | **Mandatory Spec Traceability**: Every artifact or core function generated by an AI must include a traceability tag linking to a functional requirement (e.g., `@spec RF01`). Absence yields a P1 Warning. |
| **RN03** | **Automated Test Requirement**: Any new production code submitted without a corresponding automated test file is blocked at the quality gate. |
| **RN04** | **Protection of Secrets and Hardcoded Credentials**: API keys, passwords, bearer tokens, or sensitive credentials in plaintext block the merge immediately. |

---

## 5. Use Scenarios

### Scenario 1: AI Agent submits code strictly following culture rules
* **Given that** the AI Agent generated an implementation with `@spec RF01` tag, full unit test suite, and strict type annotations
* **When** the Bend validator executes the culture audit on the files
* **Then** the report yields a Culture Score of 100%, 0 blocking violations
* **And** the process exits with `exit code 0` (Approved).

### Scenario 2: AI Agent generates code with anti-patterns (lazy code / hardcoded secret)
* **Given that** the AI Agent generated a file containing `# TODO: implement later` and an API key `secret_key_mock_...`
* **When** the Bend validator processes the file in parallel
* **Then** violations of rules `RN01` and `RN04` are detected with severity `P0_BLOCKING`
* **And** the report displays file name, line numbers, infractions, and remediation instructions
* **And** the pipeline terminates with `exit code 1` (Blocked).

---

## 6. Acceptance Criteria

1. The Bend engine (`backend/src/guardian.bend`) compiles and executes without errors via `bend run-rs` and `bend check`.
2. Culture rules are evaluated in a parallel and purely functional manner.
3. The final report details total files audited, total violations, P0/P1 counts, penalty points, and Culture Score (0 to 100).
4. The CLI (`scripts/culture_guard.py`) orchestrates file reading, executes the Bend engine, and formats output for developers and CI/CD pipelines.
