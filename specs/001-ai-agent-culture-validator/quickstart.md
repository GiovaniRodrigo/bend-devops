# Quickstart: AI Agent Culture Validator

---

## Prerequisites

- Bend (`~/.cargo/bin/bend`) and HVM (`~/.cargo/bin/hvm`).
- Python 3.12+.

---

## Execution Steps

### 1. Run Complete Validation Suite
```bash
./scripts/validate.sh
```

### 2. Audit Files via CLI
```bash
python3 scripts/culture_guard.py examples/compliant_agent_output.py
```
